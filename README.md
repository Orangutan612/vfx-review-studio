# 特效评审台 · VFX Review Studio

线上一句话就能用：**https://orangutan612.github.io/vfx-review-studio/**

---

## 这是什么

一个给游戏特效师用的**视频评审工具**。把一段特效视频交给能读图的 AI 模型，让它按你写的标准逐条给意见：
**哪一帧、哪个部位、怎么改**。

它做三件事：

1. **真正逐帧解码**，不是隔几张截一次图 —— 只亮两帧的爆点也不会被跳过。
2. **把连续运动压成接触表**：把逐帧画面拼成一张图交给模型，模型看的是动作过程，不是单张静帧。
3. **逐帧实算亮度指标**（峰值 / 均值 / 闪光占比 / 变化频率），把"感觉有点亮"变成数字，模型据此下判断。

另外自带一个 **贴图台**：在浏览器里程序化生成特效贴图，导出后直接给引擎用。

**隐私**：作品视频与参考素材**从不离开你的电脑**。逐帧解码全在浏览器里跑，
发出去的只有抽取出来的那几张截图和算好的数值 —— 而且只发给你自己填的那个模型服务。

## 怎么用 · 评审台

1. 打开线上链接。
2. 右上角 **配置模型** → 选一家服务商 → 粘贴你自己的 API Key
   （Key 只存在你这台机器的浏览器里，页面会当场验证这个模型能不能读图）。
3. **你的作品**：把视频拖进去（或点选文件），再选一段**不超过 15 秒**的连续片段。
4. 右边填三样：**作品内容**（剑气 / 爆炸 / 命中反馈…）、**特效风格**、**最想解决什么**。
5. 点 **开始评审**，等报告出来。

报告可以直接导出成**单文件 HTML**（图片全内嵌，发给谁都能打开）或 **Markdown**。

### 想横向对比？

**参考库**里放你自己的高分片段，评审时勾选，模型会把你的作品和参考放在一起比较。
加入方式：本地上传视频 / 从链接添加 / **录屏捕获**（在别的网页播视频时录下来）/ 静态参考图。

### 支持哪些模型服务

| 服务商 | 典型模型 |
|---|---|
| DeepSeek | deepseek-chat / deepseek-reasoner |
| 阿里通义百炼 | qwen-vl-max 等视觉模型 |
| 智谱 GLM | glm-4v 等 |
| 火山方舟 | doubao-vision 等 |

这些服务的 Key 都只在你的浏览器里，本站没有服务器、也不存任何人的 Key。

## 怎么用 · 贴图台（本机离线）

顶栏点 **贴图台**。它在浏览器里程序化生成特效贴图，不需要安装任何东西。

- **54 个生成器 / 15 个分类**：噪波、扭曲、径向、放射、环形、网格、有机、能量、自然现象、数字、图形、基础。
  其中「光」这一族最全：辉光 / 闪光 / 耀斑 / 星芒 / 眩光 / 神光 / 散景 / 火花 / 微光。
- **图层**：新建 / 复制 / 排序 / 显隐，13 种混合模式 + 不透明度，也能导入自己的图片当一层
  （可缩放 / 位移 / 旋转 / 翻转）。
- **参数**：滑杆 + 数字框（回车生效、Esc 撤销、↑↓ 微调、双击恢复默认）。
- **图层「变换」**：缩放 X/Y · 旋转 · 位移 · 极坐标 —— 任何生成器都能再摆一层。
- **色阶可自编**：在色带上点一下加色标、拖动改位置、改颜色或删掉。
- **我的预设**：调好一套起名存下来，下次一键载入。
- **后处理 11 项**：像素化 / 万花筒 / 漩涡 / 模糊 / 泛光 / 锐化 / 边缘检测 / 阶调化 / 暗角 / 扫描线 / 径向遮罩。
- **四方连续开关**：每一层单独控制平铺时间噪波是否按边界对齐。
- **平铺检查**：1×1 / 2×2 / 3×3 / 4×4，当场看接缝。
- **8 套内置样例**：爆炸火光 / 技能冲击波 / 魔法漩涡 / 闪电打击 / 地面裂纹 / 消融溶解 / 神圣光芒 / 做旧划痕。
- **收藏 / 最近**：常用的生成器点星标收藏。

**导出**：PNG 贴图 · 法线图 · **序列帧（编号 PNG 打包成 zip）** · **翻转书 / 序列图**（UE5 Flipbook 格式：8×8 格、每格一个小元素、四周留白，可调每格尺寸与留白）· 通道打包（R/G/B/A）· 复制到剪贴板。
文档可以存成文件、也能生成分享链接。

## 版本更新

### v1.4.1

- **本站不允许被别的网页内嵌**：被内嵌时不会正常显示，并给出提示。
  做法上说明白：GitHub Pages 不能让站点自定义响应头，`X-Frame-Options` / CSP 都用不了；
  `frame-ancestors` 写在 `<meta>` 里规范上会被忽略。静态站只剩页面内判断这一条路。
  地址加 `?embed=1` 可主动放行。

### v1.4.0

- 接上 **GPU 渲染（WebGL2 片元着色器）**：光 / 几何这一族 8 个类型已在 GPU 上跑，512² 图层 **25–80ms → 4ms**；没移植的类型自动回落 CPU。
- 修：部署后浏览器吃旧缓存导致「看不到更新」—— 现在部署时自动给资源加版本号。

## 我部署了，但打开还是旧内容？

先看**页面底部有没有一条蓝色提示条**。有的话就是浏览器缓存了这个 HTML 页 —— GitHub Pages 连 HTML 也带缓存，
部署脚本给 JS/CSS 打的版本号管不到它。点提示条上的「刷新到最新版」即可；也可以 `Ctrl+F5`，或开一个无痕窗口看一眼。

## 安全

静态站没有服务器，所以"入侵服务器"这条路本来就不存在。真正的风险只有几条，我们是这么处理的：

| 风险 | 做法 |
|---|---|
| **供应链投毒**（第三方脚本被改） | **一个外链都没有**：没有 CDN 脚本、没有外部字体、没有统计代码。样式和脚本全是仓库里的本地文件（`public/vendor/` 里的 mp4box 也是本地固定的）。自检里有一条盯着"部署目录不许出现外部脚本"。 |
| **模型输出 / 导入文件里藏脚本**（XSS → 偷 localStorage 里的 API Key） | 报告渲染对**所有**来自模型和用户的文本做 HTML 转义；自检里喂一段 `<img onerror=...>` 进去，验证它被转义。贴图台渲染图层名 / 预设名一律用 `textContent`，不走 innerHTML。 |
| **API Key 泄漏** | Key 只存在你自己的浏览器（链接版）或本机 `.env`（本地版），只发给你自己选的模型服务。**部署脚本会扫描所有要上传的文件，出现 `sk-` 就拒绝上传**；自检另有一条确认"评审链路根本不接触 Key"。 |
| **别人把本站塞进 iframe 挂广告 / 冒充** | 防内嵌：被内嵌时先尝试跳出框，跳不出去就盖层提示；地址加 `?embed=1` 才放行。 |
| **仓库被改 → 所有访客被投毒** | 这条**只能靠账号侧**，见下。 |

需要你自己做的（我代替不了）：**不要加不认识的协作者，不要合来路不明的 PR，部署前看一眼改动了哪些文件**
（部署脚本只上传 `public/` 和 README，不碰别的）。其中最重要的一条是给 GitHub 账号开**两步验证**：

1. 右上角头像 → **Settings**（设置）
2. 左侧栏 → **Password and authentication**（密码和身份验证）
3. 找到 **Two-factor authentication**（双重身份验证）那一段 → 点 **Enable two-factor authentication**
4. 选 **Authenticator app**（认证器应用，推荐）：用手机上的认证器扫它给的二维码（Microsoft Authenticator / Google Authenticator / 1Password 都行），
   再把 App 里显示的 6 位数字填进去
5. **把恢复码存好**（下载或抄到别处）→ 点「我已保存恢复代码」完成
6. 有余力再加一个**安全密钥 / 通行密钥**作备用

两个提醒：**别只图省事选短信** —— 官方明确说 TOTP 应用比短信可靠（尤其美国境外），换号或丢手机很容易把自己锁在外面；
**恢复码是丢了手机后唯一的退路**，单独存一份。（GitHub 自 2023 年 3 月起要求所有在 GitHub.com 上贡献代码的账号启用 2FA，
启用后有 28 天检查期，正常登录几次就过去了。）

**做不到的**：GitHub Pages 不允许自定义响应头，所以 HSTS / CSP / X-Content-Type-Options 这些没法由我们设。
替代办法是把能攻击的面收窄 —— **零外链 + 全部转义 + 没有服务端**。

## 常见问题

**报告里说模型的输出是空的 / 被截断了**
把「报告长度」调短一档，或把「模型思考程度」从"深入"降到"标准"。模型单次输出有上限。

**接口通了，但模型读不出图**
有些模型名字带 vision 其实不支持图片输入。换一个视觉模型，或换一家服务商。

**又慢又贵**
参考图越少越快；「报告长度」调短；把「模型思考程度」调低。

**链接打不开 / 很慢**
线上托管在 GitHub Pages，国内访问有时不稳定。等一会儿再试，或者用本地版跑（见维护文档）。

## 边界

- 本站**没有服务器**：不存你的视频、不存你的 Key、也不替你调用模型 —— 请求直接由你的浏览器发给模型服务商。
- 所以模型服务商必须允许浏览器直连（CORS）。上表列的四家都可以。
- 视频长度上限 2 分钟、单次评审片段不超过 15 秒 —— 这是为了让模型看的是"一段动作"，而不是"一部片"。
