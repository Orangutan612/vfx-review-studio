本次 · v1.4.3

旧页面自曝
  • 修：「上传了但页面没变」这不是没传上去，是浏览器把 HTML 也缓存了 —— 之前部署脚本只给 JS / CSS 打了版本号，管不到 HTML 本身。现在每个页面都带一个自曝：拿自己身上的构建号和线上 version.json（强制不走缓存地取）比一比，落后就在页面底部弹一条「你看的是旧版页面 —— 线上已经有 v…」并给一键刷新。以后再遇上"怎么没变"，页面自己会告诉你，不用猜。

上一版 · v1.4.1

v1.4.1

防内嵌
  • 本站不允许被别的网页内嵌（新）被内嵌时不会正常显示，并给出提示。做法上必须说明白：GitHub Pages 不能让站点自定义响应头，所以 X-Frame-Options / CSP 都用不了；而 frame-ancestors 写在 <meta> 里规范上会被忽略（只在响应头里生效）。静态站只剩页面内判断这一条路：检测到被嵌 → 先尝试跳出框，跳不出去就盖一层提示。地址加 ?embed=1 可主动放行。

上一版 · v1.4.0

v1.4.0

换渲染内核
  • 接上 GPU 渲染（WebGL2 片元着色器）把渲染从 CPU 搬到 GPU（WebGL2 片元着色器）。一个 512² 图层从 25–80ms 降到 4ms —— 拖滑杆不再卡顿，这才是"顺手"的关键。架构上只把「算灰度场」搬到 GPU，上色 / 后处理 / 图层 / 导出全部沿用原管线；WebGL 不可用时自动回落 CPU，不会因为 GPU 挂了就整个不能用。这一版最终把 54 个生成器全部搬上了 GPU（见下方）。
  • 验证方式同一张图，GPU 与 CPU 两条路各算一遍逐像素比：差异 0.4%–2%（星芒 0.021、闪光 0.006、辉光 0.012、花瓣 0.018）—— 说明着色器确实复现了原来的画面，不是"另画了一个"。
  • 修：部署了新版本却看不到GitHub Pages 对静态资源带缓存，HTML 里的 script/link 没有版本号，浏览器就一直吃旧文件。现在部署时自动给所有资源加上当次的版本号，每次部署必定生效。
  • 按"联络表"逐个修手感和剪贴画感把 54 个生成器全部铺成一张联络表逐个看，抓出并修掉：边缘被切平（14 个"画面里放元素"的类型现在会在贴边前淡出，融球/散景/神光不再糊在边上）、散景光斑跑到框外的放置 bug、多边形/星形/十字/月牙的纯白硬边剪贴画感（加了内部明暗，有体积了）、融球和散景默认太大糊成一坨。
  • 用 SDF 图元重做 6 个最难看的（GPU）建了一套 GLSL 图元库（cov 抗锯齿、smin 平滑并集、sdSeg 线段距离、gauss），并用它重写了融球 / 散景 / 火花 / 细胞 / 十字 / 月牙 —— 融球现在是独立柔边球体、散景是有边框的圆盘、火花是带拖尾的胶囊、细胞有明暗分块。GPU 类型从 8 个增到 14 个。
  • 第二批 6 个也重做了（GPU）神光（从画面上方洒下的宽柔光柱）· 矩阵（真正下落的数字雨，带拖尾和亮头）· 水晶（有棱面明暗的晶格）· 编织（一横一竖交织的线）· 马赛克（带斜边和间隙的砖块）· 做旧（多层污渍而不是细麻点）。GPU 类型 14 → 20 个。
  • 归属声明写清楚 + 仓库简介改准内嵌来源补上国内可直连的「贴图工坊」(vfxmento.xyz)，并在 README 里写明：两个页面都只是 iframe 引用原站，代码与内容属于原作者，本站不复制、不改写、不再分发，原作者要求即可移除。另外 GitHub 仓库简介原写「自带 API Key」容易被误解成"点进网页就有 key 用"，已改成「用你自己的模型 API Key，站点不提供」。
  • 贴图工具页只保留一个来源一度加过国内可直连的「贴图工坊」(vfxmento.xyz)，但实测它拒绝被内嵌（iframe 里显示「拒绝连接」，站点本身是活的，是不允许被别的网页嵌）。既然用不了就下掉了，README 与说明里也一并删掉。现在只保留 gameanimation 的 TextureCreate，并把「拒绝连接」的成因写进了兜底提示。
  • 修：缩略图和实际预览「不是一张脸」根因有两条：① 左栏缩略图走的是 CPU 函数，舞台走的是 GPU 着色器，两条路算的不是一个东西；② 我 GLSL 里的哈希是自己写的浮点版，和 CPU 那套 32 位整数位运算哈希结构不同，所以 GPU 出来的噪波偏"糊"。现在缩略图和舞台走同一条渲染路径，并且把 CPU 的哈希/梯度表逐位等价地移植进着色器—— 实测两边像素差 1.5%（纯 8 位量化误差）。
  • 54 个生成器全部上了 GPU把剩下 30 个（噪波族 / 图案族 / 自然现象族）一次性全搬到片元着色器，现在每一个类型都跑 GPU，拖滑杆基本不掉帧。做法是把它们的参数和算法逐个对照着转 —— 不是重画，是同一套数学换到 GPU 上算。
  • 第三批 4 个也重做了（GPU）闪电（真正的分叉雷，线段距离场 + 辉光，不再是抖动的曲线）· 溶解（有序抖动 + 噪声，边缘带亮边）· 能量场（加强，不再发灰）· 等离子（加了域扭曲，不再退化成同心圆）。GPU 类型 20 → 24 个。
  • 工坊布局重排：空白填满以前预览窗下面是一大片空白，而操作全堆在右侧一列、要一直往下滚。现在改成两列：左边类型浏览器，右边是预览窗 + 它下面并排的「图层 / 图层参数 / 文档」。需要滚动的地方只有「你展开某个折叠分组」——不再是浪费空间。
  • 工具切换器（新）顶栏中间一条显眼的切换器：作品评审 / 贴图台 / 贴图工具 / 更新说明，四个页面随时互相跳。
  • 页脚标清安全性四页页脚统一写明：作品视频与参考素材从不离开本机；API Key 只存在你的浏览器里、只发给你自己选的模型服务；本站没有服务器，不代存也不转发；贴图工具页是内嵌的第三方站点，内容属于原作者。
  • 新增「贴图工具」页（内嵌第三方）顶栏多了 贴图工具：以内嵌方式引用 gameanimation.info 的 TextureCreate（代码和内容都是他们的），并配了一份中文位置对照——按它的界面结构整理，帮你快速找到类型浏览器 / 图层栏 / 参数区 / 色阶编辑器 / 导出在哪。内嵌页面本身的文字改不了（跨域限制）。
  • 后续剩下 46 个类型按同一套模板继续搬（每个类型一段 GLSL 主体 + 一句参数映射）。

上一个中间版本
  • 生成器 20 → 54 个，分类 7 → 15 类重点补了「光」这一族：辉光 · 闪光 · 耀斑 · 星芒 · 眩光 · 神光 · 散景 · 火花 · 微光。
  • 图层「变换」任何生成器都能再叠缩放 X/Y · 旋转 · 位移 · 极坐标（横轴当角度），一键重置。
  • 后处理 11 项像素化 / 万花筒 / 漩涡 / 模糊 / 泛光 / 锐化 / 边缘检测 / 阶调化 / 暗角 / 扫描线 / 径向遮罩，每项可单独开关调参。

  • 调色与预设色标编辑器（自己加 / 拖 / 删色标）·「我的预设」存本机 · 内置色阶十几套 · 通道打包（含「空通道 / 常量 1」）· 导出压黑底。

  • 收藏 / 最近 / 动态筛选 / 按英文名搜常用的点星标收藏；搜索直接打 flare 也能找到耀斑。

还没做 / 已知取舍

  • 动画导出走「序列帧」不走 GIFGIF 只有 1 位透明和 256 色，喂引擎不够用；所以做的是序列帧（编号 PNG 打包 zip）和序列图集。需要 GIF 的话，用序列帧在 AE / PS 里转一下就有一份质量更好的。
  • 模型服务商的 CORS 差异链接版由浏览器直连模型服务，所以对方必须放行跨域。实测可用：DeepSeek / 通义百炼 / 智谱 / 火山方舟。
  • github.io 在国内访问不稳定这是托管位置的固有限制，不是代码问题。本地版可以当兜底。
