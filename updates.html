本次 · v1.3.0

大更新
  • 后处理 11 项（新）像素化 / 万花筒 / 漩涡 / 模糊 / 泛光 / 锐化 / 边缘检测 / 阶调化 / 暗角 / 扫描线 / 径向遮罩。每项可单独开关、单独调参，按「几何 → 卷积 → 调色」的顺序作用在形状做完之后 —— 实测这一步对成图质量的影响比换生成器还大。
  • 四方连续开关（新）每一层都能单独关掉「四方连续」。开着时噪波按边界对齐，关掉用普通哈希、接缝不再对齐。实测接缝差：分形噪波 0.021 → 0.141，云絮 0.045 → 0.504（关掉后扩大 6~11 倍）。
  • 改名：贴图台原来叫「贴图工坊」，现在改叫「贴图台」—— 和「评审台」凑成一套。网址没变，还是 /workshop.html。
  • 序列帧导出（新）把动画按帧导出成编号 PNG（frame_0001.png…）并打包成一个 zip —— AE / UE5 / Nuke 直接吃，带完整透明通道。比 GIF 实用：GIF 只有 1 位透明、最多 256 色，喂引擎是不够用的。
  • 收藏 / 最近（新）常用的生成器点右上角的星标收藏，类型浏览器多了「收藏」「最近」两个筛选。
  • 图片图层支持变换导入自己的图片当图层之后，可以缩放 / 左右位移 / 上下位移 / 旋转 / 水平翻转 / 垂直翻转，等比不拉变形。
  • 生成器 20 → 24 个，分类 7 → 11 类补了「放射 / 环形 / 自然现象 / 数字」四类：花瓣、同心环、水波、电路。色标从 12 套加到 16 套（日落 / 深海 / 血月 / 薄荷）。

更早 · v1.2.0

新增 · 贴图台

/workshop.html

一个在浏览器里跑的特效贴图生成器，用来做爆发、拖尾、溶解、闪电、裂纹这类要喂给引擎的图。入口在顶栏右侧的「贴图台」。

  • 20 个生成器 / 7 个分类噪波（分形噪波 · 云絮 · 湍流 · 大理石）、扭曲（漩涡）、径向（集中线 · 光芒 · 冲击环）、网格（棋盘 · 点阵 · 条纹 · 蜂窝）、有机（细胞 · 裂纹 · 划痕）、能量（闪电 · 等离子 · 溶解）、基础（渐变 · 颗粒）。
  • 图层叠加新建 / 复制 / 排序 / 显隐，13 种混合模式 + 不透明度，也能导入自己的图片当一层。
  • 参数面板滑杆 + 数字框：回车生效、Esc 撤销输入、↑↓ 按步长微调、双击恢复默认，数值自动夹进范围并对齐步长。
  • 着色三档灰度 / 单色 / 色阶（12 套内置渐变），另有「亮度转透明」——一键把黑底素材变成透明底。
  • 平铺检查1×1 / 2×2 / 3×3 / 4×4 切换。噪波用的是周期性哈希，整数密度下是真无缝。
  • 导出PNG、法线图（由灰度生成切线空间法线）、序列图集（按帧铺网格，供 UE5 翻转书用）、通道打包（R/G/B/A 各取一张图）、复制到剪贴板。
  • 无缝化把画面和它的四向镜像做加权平均，强度拉满时平铺边界在数学上完全相等（实测接缝误差 9.52 → 0.00）。纯本地算法、瞬间出结果，不联网也不耗额度；结果是新图层，原图还在。
  • 8 套内置样例爆炸火光 / 技能冲击波 / 魔法漩涡 / 闪电打击 / 地面裂纹 / 消融溶解 / 神圣光芒 / 做旧划痕。
  • 工程性撤销重做（Ctrl+Z / Ctrl+Y）、空格播放、Delete 删层、存文件 / 读文件 / 分享链接（文档能压进 URL）、浏览器里自动保存。

全程在本机浏览器里算：不上传、不联网、不依赖服务端，所以本地版和链接版行为完全一致。

还没做 / 已知取舍

  • 动画导出走「序列帧」不走 GIFGIF 只有 1 位透明和 256 色，喂引擎不够用；所以做的是序列帧（编号 PNG 打包 zip）和序列图集。需要 GIF 的话，用序列帧在 AE / PS 里转一下就有一份质量更好的。
  • 模型服务商的 CORS 差异链接版由浏览器直连模型服务，所以对方必须放行跨域。实测可用：DeepSeek / 通义百炼 / 智谱 / 火山方舟。
  • github.io 在国内访问不稳定这是托管位置的固有限制，不是代码问题。本地版可以当兜底。
