这块界面里有什么

对方界面里的文字是英文 / 日文，而内嵌的页面我们改不了（浏览器同源策略：跨域 iframe 的内容不允许被外部修改）。 所以下面这份是位置对照——按它的界面结构整理的，帮你快速找到东西在哪。

  • 类型浏览器分类、搜索、收藏、标签筛选、缩略图网格。左边那一列（或顶部）就是。
  • 图层栏新建 / 显示隐藏 / 重命名 / 缩略图，一层叠一层。
  • 参数区可折叠分区，每行是「滑块 + 数字框」。数字框能直接输入精确值。
  • 渐变色阶编辑器一条色带 + 可拖动的色标，能加色标、删色标、存成预设。
  • 导出序列图（精灵表，带预览）· 通道打包（R/G/B/A 各取一张）· 预设库。
  • 快速开始一个预设画廊，点一张卡片就能套一套参数。

建议的用法

  1. 先挑类型（分类里点），别一上来就调参数。
  2. 调参数时**先看整体形状**，形状对了再调明暗和细节。
  3. 导出前用平铺检查看一眼接缝，再做序列图 / 通道打包。
  4. 做好的参数存进预设库，下次直接套。

本机「贴图台」同样有这些功能（类型浏览器 / 图层 / 可折叠参数 / 色阶编辑器 / 翻转书 / 通道打包 / 我的预设）， 而且 不联网、不登录也能用——网络到不了这边时用它。
